## OpenRPC Generator

`OpenRPCGenerator` describes a contract or router as an [OpenRPC](https://spec.open-rpc.org) 1.3 document, with JSON Schemas from your [schema converters](/docs/openapi/specification#openapi-generator):

```ts
import { OpenRPCGenerator } from '@orpc/openrpc'
import { ZodToJsonSchemaConverter } from '@orpc/zod'

const generator = new OpenRPCGenerator({
  converters: [new ZodToJsonSchemaConverter()],
})

const spec = await generator.generate(router, {
  base: {
    info: { title: 'Planets', version: '1.0.0' },
    servers: [{ url: 'https://example.com/rpc' }],
  },
  filter: (procedure, path) => !path.includes('internal'),
})
```

Each procedure becomes a method, in the same way [OpenRPC Handler](/docs/openrpc/handler#methods-and-params) maps them:

- **Params**: an object input is described as one by-name param per property, any other input as a single by-position `input` param, and a method without input has no params.
- **Result**: the output schema, which also allows `null` when the output is optional.
- **Errors**: the [typesafe errors](/docs/error-handling) with their JSON-RPC codes. Pass the handler's `errorCodeMap` to the generator too.
- **Metadata**: `summary`, `description`, `tags`, and `deprecated` from [`openapi` metadata](/docs/openapi/specification#metadata).

Procedures with an [event iterator](/docs/async-iterator-object) are skipped, as the handler does not serve them. Reusable schemas, such as Zod schemas with `.meta({ id: 'Planet' })`, are placed in `components.schemas`.

## Service Discovery

`OpenRPCDiscoveryHandlerPlugin` answers the `rpc.discover` method with the document, as the [OpenRPC Service Discovery](https://spec.open-rpc.org/#service-discovery-method) method, and also serves it over `GET` at `/openrpc.json`, relative to the prefix:

```ts
import { OpenRPCDiscoveryHandlerPlugin } from '@orpc/openrpc/plugins'

const handler = new OpenRPCHandler(router, {
  plugins: [
    new OpenRPCDiscoveryHandlerPlugin({
      spec: () => generator.generate(router), // memoize it for production
      specPath: '/openrpc.json', // or false to disable the GET endpoint
    }),
  ],
})
```

Tools such as the [OpenRPC Playground](https://playground.open-rpc.org) can then load the document from `http://localhost:3000/rpc/openrpc.json`.
