OpenRPC serves the same router as a [JSON-RPC 2.0](https://www.jsonrpc.org/specification) API, for clients and tools of the JSON-RPC ecosystem. For oRPC's own protocol, see [RPC](/docs/rpc), and for a REST API, see [OpenAPI](/docs/openapi).

- [OpenRPC Handler](/docs/openrpc/handler): serve procedures as JSON-RPC methods, with batches and notifications.
- [OpenRPC Link](/docs/openrpc/link): call a JSON-RPC server from a typesafe client.
- [OpenRPC Adapters](/docs/openrpc/adapters): the HTTP and WebSocket adapters that run them.
- [OpenRPC Specification](/docs/openrpc/specification): generate an OpenRPC document and serve it with service discovery.
