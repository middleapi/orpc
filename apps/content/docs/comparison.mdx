oRPC, [tRPC](https://trpc.io/), [ts-rest](https://ts-rest.com/), [Hono](https://hono.dev/), and [Elysia](https://elysiajs.com/) all give you end-to-end typesafe APIs in TypeScript without code generation. This page lists what each one ships, so you can decide which fits your project.

Other frameworks were last checked on October 24, 2026, against tRPC 11.19.0, ts-rest 3.52.1, Hono 4.13.13, and Elysia 1.4.30. See [Sources](#sources).

## At a Glance

|  | oRPC | tRPC | ts-rest | Hono | Elysia |
| --- | --- | --- | --- | --- | --- |
| API style | RPC and RESTful routes from one router | RPC | RESTful routes from a contract | Web framework with typed routes | Web framework with typed routes |
| OpenAPI | First-party | Official `@trpc/openapi` (alpha), RPC paths only | First-party `@ts-rest/open-api` | Third-party middleware | Official `@elysiajs/openapi` plugin |
| Contract-first | First-party | Not supported | Required | Third-party middleware | Not supported |

## The Same Endpoint in Each

Each example finds a planet by `id` and responds with a 404 when it is missing. The `openapi` line is optional: it gives the oRPC procedure the RESTful route `GET /planets/{id}`.

<CodeGroup>

```ts oRPC
import { openapi } from '@orpc/openapi'
import { ORPCError, os } from '@orpc/server'
import * as z from 'zod'

const planets = [{ id: 'earth', name: 'Earth' }]

export const router = {
  planet: {
    find: os
      .meta(openapi({ method: 'GET', path: '/planets/{id}' }))
      .input(z.object({ id: z.string() }))
      .handler(async ({ input }) => {
        const planet = planets.find(planet => planet.id === input.id)
        if (!planet) {
          throw new ORPCError('NOT_FOUND')
        }
        return planet
      }),
  },
}
```

```ts tRPC
import { initTRPC, TRPCError } from '@trpc/server'
import * as z from 'zod'

const planets = [{ id: 'earth', name: 'Earth' }]

const t = initTRPC.create()

export const appRouter = t.router({
  planet: t.router({
    find: t.procedure
      .input(z.object({ id: z.string() }))
      .query(async ({ input }) => {
        const planet = planets.find(planet => planet.id === input.id)
        if (!planet) {
          throw new TRPCError({ code: 'NOT_FOUND' })
        }
        return planet
      }),
  }),
})

export type AppRouter = typeof appRouter
```

```ts ts-rest
import { initContract } from '@ts-rest/core'
import { initServer } from '@ts-rest/express'
import * as z from 'zod'

const planets = [{ id: 'earth', name: 'Earth' }]

const c = initContract()

export const contract = c.router({
  planet: {
    find: {
      method: 'GET',
      path: '/planets/:id',
      pathParams: z.object({ id: z.string() }),
      responses: {
        200: z.object({ id: z.string(), name: z.string() }),
        404: z.object({ error: z.string() }),
      },
    },
  },
})

export const router = initServer().router(contract, {
  planet: {
    find: async ({ params }) => {
      const planet = planets.find(planet => planet.id === params.id)
      if (!planet) {
        return { status: 404, body: { error: 'Planet not found' } }
      }
      return { status: 200, body: planet }
    },
  },
})
```

```ts Hono
import { zValidator } from '@hono/zod-validator'
import { Hono } from 'hono'
import * as z from 'zod'

const planets = [{ id: 'earth', name: 'Earth' }]

const app = new Hono().get(
  '/planets/:id',
  zValidator('param', z.object({ id: z.string() })),
  async (c) => {
    const { id } = c.req.valid('param')
    const planet = planets.find(planet => planet.id === id)
    if (!planet) {
      return c.json({ error: 'Planet not found' }, 404)
    }
    return c.json(planet, 200)
  },
)

export type AppType = typeof app
```

```ts Elysia
import { Elysia } from 'elysia'
import * as z from 'zod'

const planets = [{ id: 'earth', name: 'Earth' }]

const app = new Elysia().get(
  '/planets/:id',
  ({ params, status }) => {
    const planet = planets.find(planet => planet.id === params.id)
    if (!planet) {
      return status(404, 'Planet not found')
    }
    return planet
  },
  { params: z.object({ id: z.string() }) },
)

export type App = typeof app
```

</CodeGroup>

On the client:

| Framework | Call | Result |
| --- | --- | --- |
| oRPC | `client.planet.find({ id })` | The planet, or throws an `ORPCError` |
| tRPC | `trpc.planet.find.query({ id })` | The planet, or throws a `TRPCClientError` |
| ts-rest | `client.planet.find({ params: { id } })` | `{ status, body }`, typed per status |
| Hono | `client.planets[':id'].$get({ param: { id } })` | A typed `Response` |
| Elysia | `client.planets({ id }).get()` | `{ data, error }`, with `error` typed per status |

### Type Safety

| Feature | oRPC | tRPC | ts-rest | Hono | Elysia |
| --- | --- | --- | --- | --- | --- |
| End-to-end typesafe input/output | ✅ | ✅ | ✅ | ✅ | ✅ |
| [End-to-end typesafe errors](/docs/client/error-handling) | ✅ | 🟡 | ✅ | ✅ | ✅ |
| [End-to-end typesafe File/Blob](/docs/binary-data) | ✅ | 🟡 | 🟡 | 🟡 | 🟡 |
| [End-to-end typesafe Server-Sent Events](/docs/async-iterator-object) | ✅ | ✅ | 🛑 | 🛑 | ✅ |
| [End-to-end typesafe `ReadableStream<Uint8Array>`](/docs/binary-data#readablestreamuint8array) | ✅ | 🛑 | 🛑 | 🛑 | 🛑 |
| [Typesafe at scale](#type-checking-performance) | ✅ | ✅ | – | 🛑 | – |

oRPC types errors per procedure or globally, with [declared errors](/docs/error-handling) or an [error factory](/docs/error-handling#error-factory). tRPC (as of 11.19) has one global `errorFormatter`. ts-rest and Elysia type each response by status code. Hono types errors returned with a status code, such as `c.json({ error }, 404)`, but not a thrown `HTTPException`.

### API Design & OpenAPI

| Feature | oRPC | tRPC | ts-rest | Hono | Elysia |
| --- | --- | --- | --- | --- | --- |
| Implementation-first approach | ✅ | ✅ | 🛑 | ✅ | ✅ |
| [Contract-first approach](/docs/contract-first) | ✅ | 🛑 | ✅ | 🟡 | 🛑 |
| [OpenAPI spec generation](/docs/openapi/specification) | ✅ | 🟡 | ✅ | 🟡 | ✅ |
| [Standard Schema (Zod, Valibot, ArkType, ...)](/docs/integrations/standard-schema) | ✅ | ✅ | 🟡 | 🟡 | ✅ |
| [Native types (Date, URL, Set, Map, ...)](/docs/rpc/serializer#supported-data-types) | ✅ | 🟡 | 🛑 | 🛑 | 🟡 |
| [Custom serializers](/docs/rpc/serializer#custom-serializers) | ✅ | ✅ | 🛑 | 🛑 | 🛑 |
| [Bracket notation (nested query and form data)](/docs/openapi/bracket-notation) | ✅ | 🛑 | 🟡 | 🟡 | 🟡 |
| [Lazy router (code splitting, faster cold starts)](/docs/router#lazy-router) | ✅ | ✅ | 🛑 | 🛑 | ✅ |

oRPC serves one router over its [RPC protocol](/docs/rpc/protocol) and as [RESTful routes](/docs/openapi/handler). tRPC's `@trpc/openapi` is in alpha and only describes its RPC endpoints. ts-rest always starts from a contract. Hono's OpenAPI and contract-first support come from third-party middleware such as `@hono/zod-openapi`. ts-rest 3.52 accepts Zod only; Standard Schema support is in its 3.53 release candidate. tRPC needs a transformer for types like `Date`, and Elysia's client parses `Date` strings.

## Performance

:::warning
Treat these numbers as reference measurements. All of these frameworks are fast enough for production, the per-request difference is tiny next to your business logic, database, and network, and results vary across environments and workloads.
:::

All numbers come from [middleapi/orpc-benchmarks](https://github.com/middleapi/orpc-benchmarks) and were measured on the same machine with oRPC 2.0.0-beta.37, tRPC 11.19.0, and Hono 4.13.8. Handlers are no-ops with pass-through validation, so the results measure framework overhead only. ts-rest and Elysia are not part of these benchmarks.

### Throughput

| Scenario | oRPC | tRPC | Hono |
| --- | --- | --- | --- |
| RPC over HTTP (req/s avg) | 20,279 | 4,821 | n/a |
| RPC over WebSocket (req/s avg) | 22,979 | 5,228 | n/a |
| OpenAPI (RESTful) over HTTP (req/s avg) | 19,799 | n/a | 18,694 |

## Using oRPC With Them

- **tRPC:** [`toORPCRouter`](/docs/integrations/trpc) converts a tRPC router into an oRPC router, which you can serve with the [OpenAPI Handler](/docs/openapi/handler).
- **Hono and Elysia:** the [Hono adapter](/docs/adapters/hono) and [Elysia adapter](/docs/adapters/elysia) mount oRPC inside an existing app.
