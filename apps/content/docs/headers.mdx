---
title: "Headers"
description: "Read request headers and set response headers through oRPC context, on the server and the client."
---

Handlers and links put the request and response headers in the [context](/docs/context) as `StandardHeaders`: plain objects with lowercase keys.

## Server

```ts twoslash
import { getRequestHeaders, getResponseHeaders, os } from '@orpc/server'
import { setCookie } from '@orpc/server/helpers'

const procedure = os.handler(({ context }) => {
  const userAgent = getRequestHeaders(context)?.['user-agent']

  const responseHeaders = getResponseHeaders(context)
  if (responseHeaders) {
    responseHeaders['cache-control'] = 'no-store'
  }

  setCookie(responseHeaders, 'session_id', 'abc123')

  return { userAgent }
})
```

:::tip
[Cookie Helpers](/docs/helpers/cookie) accept these headers directly.
:::

### Providing Headers

Headers are `undefined` in [server-side calls](/docs/client/server-side) unless you provide them:

```ts twoslash
import { call, os, REQUEST_HEADERS_CONTEXT_SYMBOL, RESPONSE_HEADERS_CONTEXT_SYMBOL } from '@orpc/server'

declare const request: Request

const procedure = os.handler(() => {})
// ---cut---
import type { StandardHeaders } from '@orpc/server'

const responseHeaders: StandardHeaders = {}

await call(procedure, undefined, {
  context: {
    [REQUEST_HEADERS_CONTEXT_SYMBOL]: Object.fromEntries(request.headers),
    [RESPONSE_HEADERS_CONTEXT_SYMBOL]: responseHeaders,
  },
})
```

## Client

```ts twoslash
import type { RouterClient } from '@orpc/server'
import { os } from '@orpc/server'

const router = { planet: { find: os.handler(() => ({ name: 'Earth' })) } }

declare const client: RouterClient<typeof router>
// ---cut---
import type { StandardHeaders } from '@orpc/client'
import { REQUEST_HEADERS_CONTEXT_SYMBOL, RESPONSE_HEADERS_CONTEXT_SYMBOL } from '@orpc/client'

const responseHeaders: StandardHeaders = {}

await client.planet.find(undefined, {
  context: {
    [REQUEST_HEADERS_CONTEXT_SYMBOL]: { 'x-tenant-id': 'acme' },
    [RESPONSE_HEADERS_CONTEXT_SYMBOL]: responseHeaders,
  },
})

const remaining = responseHeaders['x-ratelimit-remaining']
```

Link interceptors and plugins can use `getRequestHeaders` and `getResponseHeaders` too. For a typed client context, extend `HeadersContext`:

```ts twoslash
import type { HeadersContext } from '@orpc/client'

interface ClientContext extends HeadersContext {
  token?: string
}
```

:::warning
Browsers only expose cross-origin response headers listed in the [CORS Plugin](/docs/plugins/cors)'s `exposeHeaders`.
:::
