:::

Resolve the Better Auth session in middleware, typed from your auth instance.

## Installation

```package-install
npm install @orpc/better-auth@beta better-auth
```

## Setup

Add the [Request Headers Plugin](/docs/plugins/request-headers) and the [Response Headers Plugin](/docs/plugins/response-headers). The middlewares read the session from `reqHeaders` and forward Better Auth's cookies to `resHeaders`.

```ts
import type { RequestHeadersHandlerPluginContext, ResponseHeadersHandlerPluginContext } from '@orpc/server/plugins'
import { os } from '@orpc/server'
import { RequestHeadersHandlerPlugin, ResponseHeadersHandlerPlugin } from '@orpc/server/plugins'

interface ServerContext extends RequestHeadersHandlerPluginContext, ResponseHeadersHandlerPluginContext {}

const base = os.$context<ServerContext>()

const handler = new RPCHandler(router, {
  plugins: [
    new RequestHeadersHandlerPlugin(),
    new ResponseHeadersHandlerPlugin(),
  ],
})
```

:::info
The `handler` can be any supported oRPC handler, such as [RPCHandler](/docs/rpc/handler), [OpenAPIHandler](/docs/openapi/handler), or a custom one.
:::

## Protected Procedures

`requireSession` throws `UNAUTHORIZED` without a session. `optionalSession` gives `null`:

```ts
import { optionalSession, requireSession } from '@orpc/better-auth'
import { auth } from './auth'

const router = {
  me: base
    .use(requireSession({ auth }))
    .handler(({ context }) => context.session.user),

  greeting: base
    .use(optionalSession({ auth }))
    .handler(({ context }) => `Hello, ${context.session?.user.name ?? 'guest'}`),
}
```

`auth` can also be a function that returns the instance:

```ts
const procedure = os
  .$context<ServerContext & { auth: typeof auth }>()
  .use(requireSession({ auth: ({ context }) => context.auth }))
```

## Permissions

Extend `requireSession` with `.use` to check [access control](https://better-auth.com/docs/plugins/admin#access-control) permissions:

```ts
import { requireSession } from '@orpc/better-auth'
import { ORPCError, os } from '@orpc/server'
import { auth } from './auth'

function requirePermission(permissions: Record<string, string[]>) {
  return os
    .middleware(requireSession({ auth }))
    .use(async ({ context, next }) => {
      const { success } = await auth.api.userHasPermission({
        body: { userId: context.session.user.id, permissions },
      })

      if (!success) {
        throw new ORPCError('FORBIDDEN')
      }

      return next()
    })
}

const router = {
  listUsers: base
    .use(requirePermission({ user: ['list'] }))
    .handler(async () => {
      // ...
    }),
}
```

For the [organization plugin](https://better-auth.com/docs/plugins/organization), call `auth.api.hasPermission({ headers: context.reqHeaders, body: { permissions } })` in a `base.middleware`.

## Deduplication

The session is looked up once per request, even when the middlewares run more than once (see [Dedupe Middleware](/docs/recipes/dedupe-middleware)). Set `dedupe: false` to look it up on every call, for example when one `reqHeaders` serves a long-lived [WebSocket](/docs/adapters/websocket) connection:

```ts
const procedure = base.use(requireSession({ auth, dedupe: false }))
```

## Server-Side Calls

In [server-side calls](/docs/client/server-side), pass the request headers as `reqHeaders`, and optionally `resHeaders` to receive Better Auth's cookies:

```ts
import { call } from '@orpc/server'

const resHeaders = new Headers()

const user = await call(router.me, undefined, {
  context: { reqHeaders: request.headers, resHeaders },
})
```
