## Usage

```ts
import { RetryAfterLinkPlugin } from '@orpc/client/plugins'

const link = new RPCLink({
  plugins: [new RetryAfterLinkPlugin()],
})
```

:::info
The `link` can be any supported oRPC link, such as [RPCLink](/docs/rpc/link), [OpenAPILink](/docs/openapi/link), or a custom one.
:::

:::warning
Requests whose body is a [`ReadableStream`](/docs/binary-data#readablestreamuint8array) or an [`AsyncIteratorObject`](/docs/async-iterator-object) are never retried. The first attempt consumes the body, so it cannot be resent, and the plugin returns the first response as-is.
:::

## Options

By default, the plugin retries only requests that receive a `429` (Too Many Requests) or `503` (Service Unavailable) status code. It allows up to 2 retries after the first request, 3 attempts in total, and stops retrying once the total wait would exceed 5 minutes. You can customize this behavior with the following options:

```ts
const link = new RPCLink({
  plugins: [
    new RetryAfterLinkPlugin({
      shouldRetry: (response) => [429, 503].includes(response.status),
      timeout: 5 * 60 * 1000, // 5 minutes
      maxRetries: 2, // Retries after the first request, so up to 3 attempts in total
    }),
  ],
})
```
