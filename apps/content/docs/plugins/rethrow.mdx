## Usage

```ts
import { RethrowHandlerPlugin } from '@orpc/server/plugins'

const handler = new RPCHandler(router, {
  plugins: [
    new RethrowHandlerPlugin({
      filter: (error, options) => {
        // Example: Rethrow all non-ORPCError errors
        return !(error instanceof ORPCError)
      },
    }),
  ],
})

try {
  await handler.handle(request)
}
catch (error) {
  // If the filter returns true, the error can be caught here
}
```

:::info
The `handler` can be any supported oRPC handler, such as [RPCHandler](/docs/rpc/handler), [OpenAPIHandler](/docs/openapi/handler), or a custom one.
:::

## Batch Requests

With the [Batch Plugin](/docs/plugins/batch), a rethrown error fails the whole batch instead of a single call.

- In `buffered` mode, `handler.handle()` rejects with the error, so it can be caught as above.
- In `streaming` mode, `handler.handle()` has already resolved with a streaming response, so the error cannot be caught around it. It errors the response stream instead, and reaches whatever consumes the response body.
