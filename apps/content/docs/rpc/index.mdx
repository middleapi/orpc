RPC is oRPC's default protocol between its own clients and servers. It works over HTTP, WebSocket, and message ports. To serve a REST API from the same router, see [OpenAPI](/docs/openapi).

- [RPC Protocol](/docs/rpc/protocol): how calls are routed, encoded, and answered.
- [RPC Serializer](/docs/rpc/serializer): the types supported beyond JSON, and how to add your own.
- [RPC Handler](/docs/rpc/handler): serve procedures on the server.
- [RPC Link](/docs/rpc/link): call an RPC Handler from a client.
- [RPC Adapters](/docs/rpc/adapters): the HTTP, WebSocket, and message port adapters that run them.
